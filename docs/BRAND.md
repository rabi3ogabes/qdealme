# QDealMe brand

## Slogan

**Chosen:** Smart deals. Zero noise. / **عروض ذكية. بلا ضجيج.**

It says exactly what makes QDealMe different from the ad-heavy flyer sites: the deals are smart (verified, comparable) and the experience is calm (no pop-ups, no ads inside flyers). It is short enough for the header badge, the footer, app-store listings and social bios, and it works equally well in Arabic and English.

### Shortlist (for campaigns, ads and social)

| English | Arabic | Best used for |
|---|---|---|
| Smart deals. Zero noise. | عروض ذكية. بلا ضجيج. | Main slogan, site header, store listings |
| Every deal in Qatar. One calm place. | كل عروض قطر. في مكان واحد هادئ. | Homepage hero, SEO descriptions |
| Shop smarter in Qatar. | تسوّق بذكاء في قطر. | Short ads, push notifications |
| Real prices. Real savings. | أسعار حقيقية. توفير حقيقي. | Campaigns about verified prices |
| Your deals, beautifully simple. | عروضك، ببساطة وأناقة. | Premium / brand campaigns |
| Q for Qatar. Deal for you. | Q لقطر. والعرض لك. | Playful social posts that explain the name |

The name reads as **"Q Deal Me"**: *Q* for Qatar, and "deal me" as an invitation. In Arabic marketing it can be written as **كيو ديل مي**.

## Visual identity

| Token | Value | Use |
|---|---|---|
| Primary (Qatar maroon) | `#5e1f38` / dark mode `#c76f91` | Buttons, active states, prices |
| Accent (soft gold) | `#c9a227` | Savings badges, highlights, the dot in the logo |
| Neutrals (warm sand) | `#fbf9f5` → `#1e1b18` | Backgrounds and text |
| Typeface | Readex Pro (self-hosted, Arabic + Latin) | All UI text |

The logo mark is a rounded maroon square with a white "Q" whose tail doubles as a price-tag notch, and a gold dot for "the deal". Files: `public/favicon.svg`, `public/images/logo.svg`, `public/images/logo-dark.svg`, `public/images/icon-512.png`, `public/images/og-default.png`.
